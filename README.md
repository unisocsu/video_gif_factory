# ממיר וידאו ל-GIF

תוכנה פשוטה ל-Windows שממירה קובץ וידאו לקובץ GIF, עם בחירת איכות ומהירות.

## הורדה
1. היכנסו לכרטיסייה **Actions** בריפו.
2. בחרו את ההרצה האחרונה שהסתיימה בהצלחה.
3. בתחתית הדף, בחלק **Artifacts**, הורידו את הקובץ `VideoToGif-windows`.
4. פתחו את הקובץ `VideoToGif.exe`. אין צורך להתקין דבר נוסף.

## שימוש
1. בחרו קובץ וידאו.
2. בחרו איכות (רזולוציה): קטן, בינוני או גדול.
3. בחרו מהירות תנועה. פחות פריימים בשנייה מקטינים את הקובץ.
4. אם רוצים, הגבילו את אורך ה-GIF לכמה שניות. 0 פירושו כל הסרטון.
5. לחצו על **המר ל-GIF** ובחרו היכן לשמור.

## בנייה ידנית
אם אתם רוצים לבנות את התוכנה במחשב שלכם:
1. התקינו Python 3.12 ומעלה.
2. הורידו את `ffmpeg.exe` והניחו אותו בתיקיית הפרויקט.
3. הריצו: `pip install pyinstaller`
4. הריצו: `pyinstaller --onefile --windowed --name VideoToGif --add-binary "ffmpeg.exe;." video_to_gif.py`
5. הקובץ ייווצר בתיקיית `dist`.
